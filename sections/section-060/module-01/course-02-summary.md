# Summary

Application security validates untrusted input, checks permission for the specific data and operation, protects sensitive values and maintains dependencies. Authentication alone does not authorize every business action.

Resource limits and platform segmentation reduce selected consequences, while code must bound expensive work and handle retries safely. Review the full request and data contract rather than assuming container hardening establishes application correctness.
