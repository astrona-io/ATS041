# Artifact Repository and Image Security

This section teaches artifact and image assurance. These ideas help you explain system behavior and choose a suitable approach in a KCSA scenario.

You will work through Artifact And Image Assurance. Each module introduces its goals, teaches the concepts through examples, and closes with a summary. Reusable YAML checkpoints review related objectives after selected section summaries. The course assessment index records their placement and coverage.

## Learning Outcomes

- Distinguish artifact identity, publisher trust and vulnerability evidence.
- Explain credential exposure through image and repository workflows.
- Relate verification results to the exact deployed digest.
- Identify residual risk after a passed supply-chain check.
