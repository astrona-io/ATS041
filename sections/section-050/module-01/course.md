# Artifact And Image Assurance

This module develops the reasoning needed to distinguish artifact identity, publisher trust and vulnerability evidence.

## Learning Goals

- Distinguish artifact identity, publisher trust and vulnerability evidence.
- Explain credential exposure through image and repository workflows.
- Relate verification results to the exact deployed digest.
- Identify residual risk after a passed supply-chain check.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
