# Controls, Risk And Frameworks

This module develops the reasoning needed to distinguish a threat, vulnerability, risk and security control.

## Learning Goals

- Distinguish a threat, vulnerability, risk and security control.
- Compare preventive, detective and corrective control purposes.
- Explain how a framework organizes controls and evidence.
- Evaluate a control's implementation and residual risk.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
