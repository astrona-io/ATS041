# Controls and Frameworks

This section teaches controls, risk and frameworks. These ideas help you explain system behavior and choose a suitable approach in a KCSA scenario.

You will work through Controls, Risk And Frameworks. Each module introduces its goals, teaches the concepts through examples, and closes with a summary. Reusable YAML checkpoints review related objectives after selected section summaries. The course assessment index records their placement and coverage.

## Learning Outcomes

- Distinguish a threat, vulnerability, risk and security control.
- Compare preventive, detective and corrective control purposes.
- Explain how a framework organizes controls and evidence.
- Evaluate a control's implementation and residual risk.
