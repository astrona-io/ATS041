# Summary

Shared responsibility follows the actual service contract. Managed offerings transfer selected duties while workload configuration, access and application data commonly remain customer concerns.

Infrastructure identities can affect machines, networks and stored data beyond ordinary API permissions. Scope their authority, protect metadata and credential paths, and coordinate recovery across provider and customer boundaries. Network restriction, authentication and encryption protect distinct stages.
