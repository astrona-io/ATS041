# Cloud And Infrastructure Responsibilities

This module develops the reasoning needed to explain shared responsibility for managed and self-managed infrastructure.

## Learning Goals

- Explain shared responsibility for managed and self-managed infrastructure.
- Identify powerful infrastructure identities and their workload impact.
- Compare network exposure controls with application permissions.
- Relate recovery and metadata access to infrastructure protection.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
