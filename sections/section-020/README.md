# Cloud Provider and Infrastructure Security

This section teaches cloud and infrastructure responsibilities. These ideas help you explain system behavior and choose a suitable approach in a KCSA scenario.

You will work through Cloud And Infrastructure Responsibilities. Each module introduces its goals, teaches the concepts through examples, and closes with a summary. Reusable YAML checkpoints review related objectives after selected section summaries. The course assessment index records their placement and coverage.

## Learning Outcomes

- Explain shared responsibility for managed and self-managed infrastructure.
- Identify powerful infrastructure identities and their workload impact.
- Compare network exposure controls with application permissions.
- Relate recovery and metadata access to infrastructure protection.
