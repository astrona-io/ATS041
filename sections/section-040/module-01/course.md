# Isolation And Containment Boundaries

This module develops the reasoning needed to explain container and virtual-machine isolation boundaries.

## Learning Goals

- Explain container and virtual-machine isolation boundaries.
- Distinguish Linux namespaces from Kubernetes namespaces.
- Relate process privileges and host access to containment.
- Compare resource, network and identity segmentation.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
