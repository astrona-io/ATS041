# Security Across Cloud, Cluster, Container And Code

This module develops the reasoning needed to identify the asset and responsibility at each of the four security layers.

## Learning Goals

- Identify the asset and responsibility at each of the four security layers.
- Explain how failure in an outer layer can undermine inner controls.
- Compare preventive, detective and corrective protections.
- Apply defense in depth to an application scenario.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
