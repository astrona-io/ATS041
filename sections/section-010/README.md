# The 4Cs of Cloud Native Security

This section teaches security across cloud, cluster, container and code. These ideas help you explain system behavior and choose a suitable approach in a KCSA scenario.

You will work through Security Across Cloud, Cluster, Container And Code. Each module introduces its goals, teaches the concepts through examples, and closes with a summary. Reusable YAML checkpoints review related objectives after selected section summaries. The course assessment index records their placement and coverage.

## Learning Outcomes

- Identify the asset and responsibility at each of the four security layers.
- Explain how failure in an outer layer can undermine inner controls.
- Compare preventive, detective and corrective protections.
- Apply defense in depth to an application scenario.
